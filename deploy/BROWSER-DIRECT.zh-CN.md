# 浏览器直连 B.AI

GitHub Pages 的网页可直接向固定地址 `https://api.b.ai/v1` 发请求，不需要本机执行器。浏览器会带 Authorization 头，因此 B.AI 必须允许当前网页来源的 CORS 预检和实际请求。

打开网站“多模型聚合采样”，使用浏览器直连入口输入自己的 B.AI 密钥，读取账号模型目录。选择模型、添加到市场，再填写题目和品牌，明确点击运行。读取目录不提交模型回答；付费回答只在明确运行后请求，不自动重试或切换模型。

密钥只存于当前页面内存，不写入 localStorage、sessionStorage、网址、代码或下载证据。刷新或断开后需要重新连接。页面运行期间浏览器和该页面脚本能够使用密钥，因此这是个人会话连接，不是隐藏共享密钥的服务器方案。不要把正式密钥嵌进 GitHub 或发给网页访问者。

此方式接入现有手动题集采样，每次 1–10 道题、最多 64 次请求；只支持 Chat Completions 文本协议，不请求联网搜索。官网字段仅记录测量对象，不会由浏览器跨域抓取官网。它不提供服务器上的 30 题自动出题、后台任务持久保存或团队共享任务。

连接失败可能是跨域策略、网络、浏览器扩展或服务不可用；浏览器的通用网络异常不能确诊为 CORS。若服务不允许跨域，网页无法自行解除服务端限制，需要改用受控后台。本项目不使用公共 CORS 代理，也不关闭浏览器安全设置。

运行中的页面关闭或断开时会中止浏览器请求，但服务商已收到的请求仍可能计费；这不表示服务商已取消任务。截断、缺失和失败回答不作为零分；页面采样的提及分不等同于整个品牌的 GEO 诊断总分。
