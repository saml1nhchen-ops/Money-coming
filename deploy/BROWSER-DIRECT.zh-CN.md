# 原三步诊断页：浏览器直连 B.AI

进入 `dist/#/w/demo/research`，在同一页连接 B.AI，填写品牌与市场，在第二步选择真实目录中的固定模型，再明确点击开始。无需另去聚合采样页面添加模型；连接后可在同一文档中切换页面，密钥会话保持在内存。刷新或退出需要重新连接。

## 运行范围

- 原流程：填写品牌 → 选择 AI → 查看结果，不提供品牌专用的独立入口。
- 每次固定 30 道不同问题，最多两家厂商，每家一个模型，每题每模型一次。
- 自动出题分三批，每批十题：21 道自然发现、5 道品牌认知、4 道比较题。真实题型仍按题面识别。
- 两模型全流程最多 3 次生成 + 60 次回答 = 63 次聊天调用；一模型最多 33 次。只生成题目最多 3 次；审核后明确采样是另一个最多 60 次的任务。
- 生成每次最多 4096 输出 token，回答每次最多 2048。实际价格/费用未知，调用次数上限不是金额封顶或每日限额。
- 先完成并去重出完整题库，再把同一组问题原样询问所选模型。失败、截断或去重不足时不自动补题、不重试、不切模型。

这是对本批 API 回答的可见度分析。**浏览器模式不抓取品牌官网**；官网地址仅作对象与域名归属标识，出题依据用户填写的品牌、产品、竞品和背景。不会生成假官网内容、技术 SEO 分数、用户搜索量或 AI App 全市场排名。模型候选可见不等于 Chat Completions 兼容，实际调用结果才是证据。

## 报告和证据

先展示本批提及分与主要结论，再展示竞品差距、引用证据和行动。每道题有独立卡片，可展开查看所有所选模型的回答、状态和引用。只对完整、未点名跟踪品牌/竞品/产品的自然发现回答计分；未知保留为空，提及不等于推荐。明确编号列表才给位置，回答中的普通链接不算原生引用。来源缺失不能证明官网不可引用。

可导出已脱敏的实际响应、请求/返回模型 ID 和 SHA256。停止会保留当前在途调用的结果并阻止后续调用；已提交请求可能计费。退出/更换连接会中止浏览器请求并清除本页任务，不能保证撤销服务商已接收的任务。重分析已有回答不再调用模型。

## 密钥、会话和网络

密钥仅存在私有 JavaScript 闭包中，不写 localStorage、sessionStorage、网址、源码、日志或导出。本轮浏览器研究草稿、题库和任务也仅在内存，退出清除题库与报告，保留当前表单的品牌背景。不会主动删除旧版本已保存的本地草稿。

研究流程与独立手动采样共享一个任务锁；最多一个在途请求，每次研究最多 63 次提交，失败也占本次次数。退出、重连或旧任务完成不能释放新会话的锁或写回旧结果。

请求固定发送到 `https://api.b.ai/v1`，使用 HTTPS、Bearer 认证、`credentials:omit`、`redirect:error`；目录超时 20 秒，聊天超时 120 秒，响应最多 8 MiB。B.AI 必须允许浏览器跨域预检与实际请求。认证失败显示 HTTP 状态、可用的服务端错误说明和请求编号，说明先脱敏再作为文本显示；不能仅凭通用 401 判断是用户操作或密钥问题。不使用公共 CORS 代理或关闭浏览器安全设置。

浏览器网络与聊天助手云环境分别配置。在网页内填写 Cremo 或其他官网，不需要为聊天云环境逐品牌放行域名。聊天助手也不能读取另一台设备浏览器的内存密钥或代点击其运行按钮。

## 验证边界

`node tests/test_browser_research_engine.cjs` 使用离线 Python 黄金报告和合成 transport 核对评分、调用上限、停止与重分析。`node tests/browser_research.cjs` 需要 Playwright 与 Chromium（可用 CHROMIUM_PATH 指定），会拦截全部目标网页与 B.AI 响应，不调用真实模型。报告展示还有 `test_report_summary.cjs`、`test_question_cards.cjs`。

这些检查不等于 Cremo 实采，也不证明当前账号权限、模型兼容性、真实计费或公网部署完成。真实运行必须在用户已连接的网页中明确开始。
