# 当前任务：官网输入到完整诊断报告

状态：实施中。用户已批准完整方案及发布；本轮复用已有后端、前端、验收角色，不创建新智能体。当前聊天负责接口约定、整合、回归与线上核验。

## 业务流程

默认进入工作台全览；从官网生成：输入网址和市场 → 确认品牌/产品/竞品 → 确认模型及预计30题调用范围 → 运行 → 持久报告/历史/导出/分享。客户→项目→品牌/市场/题集；团队共管，暂不开放客户账号。手动复测与可比趋势，暂不开定时任务。

## 实施约束

- 官网与模型表现分别说明，不直接叠加旧官网分数与v0.1六维计分；未知保留区间与覆盖率。
- 复用有限抓取、robots与网络安全、模型预算/互斥闸；中断不自动重放付费任务。
- 原始证据及历史schema不覆盖；历史数据属于内部项目，不直接分享。
- 报告分享是独立不可变快照，默认30天、可撤销；无客户账号，不公开列表和任务。
- 来源及技术过程字段折叠；不增加免费AI/待核对等主界面徽标。

## 验收

实际浏览器→实际网关→离线采集/采样fixture全闭环；HTTP200空正文、反爬、超时、部分模型失败；v0.1校验、未知口径、原生引用；幂等、刷新与进程重启恢复；客户项目归属、分享过期/撤销/错误ID；历史兼容；HTML/JSON/PDF来源一致；真实三品牌采集。不得用fixture宣称真实模型采样成功。
