## 页面入口与职责

- `dist/index.html` 是静态入口，含 `#app`、`#overlay` 与状态提示；加载 `style.css`、`research-ui.css`，无前端构建步骤。
- 脚本依次加载 `app.js` → `diagnostic.js` → `tool-center.js` → `ai-api.js` → `bai.js` → `research.js` → `research-ui.js` → `report-summary.js`。使用普通脚本共享全局作用域，顺序必须保留。
- `dist/app.js` 管理基础工作台、hash 路由、示例数据、通用抽屉及转义函数。路由形式为 `#/w/<workspace>/<page>`；自动诊断默认入口为 `http://127.0.0.1:8772/#/w/demo/research`。
- `dist/research.js` 管理模型状态、任务、轮询和 API 请求；`dist/research-ui.js` 将页面组织为填写品牌、选择 AI、查看结果三步，包含 CN/US 草稿、历史报告及明细。草稿保存在 localStorage，模型令牌在内存。
- `dist/report-summary.js` 最后定义 `researchReport`，覆盖 research-ui 中同名函数。当前报告顺序为结论 → 竞品差距 → 引用证据 → 下一步行动 → 报告明细；明细仍复用 `researchResultBody` / `geoReport`。
- 竞品差距按题目聚合，引用证据仅含完整且 eligible 的发现题回答中的 `citation`。`reportOpenEvidence` 打开原始回答抽屉，正文和记录详情经过转义，外链检查 http/https。
- `dist/research-ui.css` 管理分析与报告布局，现有断点包括 1250、1000、767px；本轮仅源码检查，未完成浏览器视觉或可访问性实测。

## API 与服务依赖

自动诊断服务源码为 `tools/geo_flow.py`，端口 8772。`geoLocal()` 仅允许 hostname 为 `127.0.0.1` 或 `localhost` 且端口为 8772 的页面自动配对。除 session 外，`geoFetch` 请求附 Bearer 令牌。

| 请求 | 页面用途 | 调用边界 |
|---|---|---|
| GET `/api/geo/session` | 获取当前执行器 token | 只读配对 |
| GET `/api/geo/state` | runner.profiles、busy、runs | 只读 |
| GET `/api/geo/run?id=…` | 获取任务、题目、样本、报告 | 运行中每 2500ms 轮询 |
| GET `/api/geo/export?id=…` | 下载完整分析证据 | 只读 |
| POST `/api/geo/plan` | 核对调用计划 | 不调用模型 |
| POST `/api/geo/start` | 自动出题并分析；generate_only 可仅出题 | 会调用模型，本轮未执行 |
| POST `/api/geo/sample` | 使用已有题集采样 | 会调用模型，本轮未执行 |
| POST `/api/geo/resume` | 继续未完成任务 | 会继续调用模型，本轮未执行 |
| POST `/api/geo/stop` | 停止后续调用 | 当前调用完成后停止 |
| POST `/api/geo/analyze` | 按当前品牌、SKU、竞品重新分析 | 不调用模型 |

请求主体来自 `geoPayload()`：market、website、brand_aliases、skus、competitors、context、focus、count、repeats、generator、providers、prompts。报告呈现依赖 `groups.discovery.models`（兼容 models）、samples、gaps、sources，任务依赖 config、status、plan、prompts 等；字段或含义变更须与后端及产品协调。

模型连接管理另指向 8771 的 B.AI 页面和 8770 的官方 API 页面，Windows `start-signal.ps1` 联合启动这些服务。基础工作台 `app.js` 还访问 `/api/bootstrap`、`/api/seed`、`/api/action`；历史 `server.py` 位于 8765，单独启动它不能视为已启动 8772 的完整诊断流程。在线静态入口不生成虚构报告分数。
