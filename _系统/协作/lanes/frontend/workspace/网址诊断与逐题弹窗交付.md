# 网址诊断与逐题弹窗：前端交付

2026-10-21；任务分支 `url-diagnosis-flow`。前端实现完成，待产品组织独立功能验收；未调用付费模型、未发布。

## 修改文件

- `dist/website-inspect.js`：URL-only 页面检查，复用 `/api/geo/inspect`，无需先填写品牌或连接模型；单独展示网页准备度、检查依据、方法、抓取记录与 unknown。不确认候选品牌不得进入模型采样；候选确认保留用户精确别名，不覆盖用户已编辑背景。URL 改变后旧诊断失效，失败不生成分数。
- `dist/question-cards.js`：所有 `job.prompts` 每题独立卡片；生成中或无 report 也显示。完整 config.providers 逐模型下钻，question_index/provider 严格匹配，不按重复题面合并。优先 report.samples 分析、保留原始样本及 repeat；未运行、等待、失败、截断、缺少分析保持可见且不算零分。弹窗展示原文、提及、竞品、官网原生引用、明确列表位置与证据、请求/返回模型、原始记录；引用类型分开标注。
- `dist/index.html`：按依赖顺序加载两个新脚本、更新修改资源版本。
- `dist/research-ui.js`：品牌页增加 URL 读取按钮、品牌确认门槛及诊断区域，未配置模型提示不阻碍页面检查；改“推荐”为“提及”，保留既有模型工作流、默认市场、用户草稿和30题行为。
- `dist/report-summary.js`：在主要结论后、竞品差距前插入完整题库卡片，不改变得分规则。
- `dist/research-ui.css`：页面检查、问题卡片与弹窗样式，移动端单列、长文本换行。
- `tests/test_question_cards.cjs`：新增语义与交互入口回归；本目录 worklog 为交付记录。

新增测试覆盖：无需模型的 URL 检查、候选确认阻断与精确别名保留、用户背景不覆盖、网页 null 分数、完整题库与模型集合、重复题按索引区分、重复采样、缺失/失败/截断、未知不当零、冻结模型名、引用类型和不安全文本转义。

主协调通过真实 HTTP 与 Chromium 执行 `tests/browser_url_flow.py`，已回报受控集成通过：30题、2模型、partial任务33条样本，涵盖429失败、未运行、Escape、焦点恢复、XSS及移动端无横向溢出。证据 `/tmp/geo-url-flow-evidence/summary.json`、`desktop.png`、`mobile-dialog.png`；本岗位读取 summary 并查看 mobile-dialog 截图。summary 标记 synthetic=true、browser_errors=[]；这些是确定性受控数据，不是 Cremo 真实网页或真实模型测量。精确别名修复在上述浏览器首次验证后完成，补有 CJS 回归，可由独立验收复跑浏览器。

## 复现入口

URL 检查按钮 `#inspect-website-button`；结果 `#website-inspection`，网页准备度 `#website-readiness-score`；需要确认的候选按钮 `#confirm-inspected-brand`。题库 `#question-cards`；第 n 道卡片 `#question-card-<n-1>`、`data-question-index`；弹窗 `.rq-dialog`，每模型 `.rq-model[data-provider]`。沿用现有 modal/head 的 Escape 与焦点处理；额外处理轮询重建卡片后按原索引恢复焦点。
