# 官网候选识别

团队工作台中输入公开官网，停顿约 700ms 或离开输入框后提交一次异步识别。必须先登录；页面加载、登录恢复和旧草稿恢复不会提交。名称与产品仅在第一步、字段未被手动修改时填入；竞品需要点击采用。所有候选均可查看依据并编辑，不会自动开始 30 题分析。

服务器使用现有公开地址校验、逐次重定向校验、DNS 固定连接和 2MB 上限读取官网。网页内容作为不可信数据处理，不执行脚本。读取失败时保留手工输入，不伪造证据。

## 免费 Gemini 边界

此功能仅允许经供应商官方计费字段语义核实的固定免费 Gemini。公开文档返回 403，未认证模型目录返回 401；当前没有可靠的免费字段协议证据。因此生产默认不调用补充模型，仍可从官网提取品牌和产品；竞品暂需手填。测试中的模型目录和回答为合成数据，不代表实际 B.AI 型号或免费额度。未来启用须补充官方证据、真实脱敏目录 fixture 和独立验收，不能凭名字包含 free 或默认研究 Gemini 型号认定免费。

接口仅接受官网、市场和请求 ID；客户端不能指定模型、提示词、供应商地址或密钥。若将来启用已核实的协议，每次识别最多一次非搜索聊天，不重试、不回退付费模型，提交前再次检查目录并预留调用预算。实际账单金额未知，不把调用次数当作费用。

## 缓存与部署

识别状态保存到 runtime/enrich/index.sqlite3，沿用现有持久卷。相同规范化官网与市场复用 24 小时结果；请求 ID 不得换站复用。失败和中断也保留，不自动重复模型请求。识别期间工作台 busy，部署维护会等待/阻止新调用；不改变已有报告、研究配置或供应商连接。

前端随 main 发布；后端需正式 Release。需要前后端均完成部署后使用，旧后台会返回未支持接口。

验证：Python 接口/预算/缓存/维护/目录变化测试；Chromium 合成接口测试（真实 team.html 入口、竞态、用户编辑保护、候选转义、无自动研究）。真实模型调用仍未验证。
