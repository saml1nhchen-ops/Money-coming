## 使用

打开[团队工作台](https://saml1nhchen-ops.github.io/Money-coming/dist/team.html?v=0.5.0#/w/demo/research)，在客户与项目中建立归属，再输入官网、确认品牌信息、选择模型与调用范围并开始。任务可以通过历史和固定详情链接重新打开，刷新不重复提交。

报告包含官网规则、竞品与逐题回答、引用及行动；支持HTML/JSON/打印PDF。客户项目报告可创建30天只读链接并撤销。手动复测冻结原题，比较前检查口径。不启用定时采样，不创建客户账号，同团队共管客户。旧格式保留在内部历史项目，不自动对外发布。
