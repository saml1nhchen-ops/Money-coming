# 网站 GEO 准备度

用户流程：输入官网 → 确认品牌、产品、竞品 → 网站规则报告 → 导出。网站审计与真实模型推荐测试分别展示；本网站技术分不代表推荐概率。网站流程不调用模型，不要求供应商密钥；需登录团队后台。

## 实际集成工具

- [Protego](https://github.com/scrapy/protego) 0.7.0，BSD-3-Clause：解析 robots.txt，按 UA 与路径判断规则。抓取、HTTP状态与缓存由本项目控制，工具不下载网站。没有公开的精确匹配行接口，因此证据展示相关原文与解析结论，不假造精确命中行。
- [Trafilatura](https://github.com/adbar/trafilatura) 2.3.1，Apache-2.0：从已安全读取的 HTML 提取正文。不使用它的下载函数，不执行 JavaScript。其正文长度只是可读性线索。

版本及全部传递依赖在 tools/requirements-audit.lock 锁定 SHA256；Docker 用独立 Python venv 安装 wheel，保留包内许可证。开发环境可创建 venv 后执行 `python -m pip install --only-binary=:all: --require-hashes -r tools/requirements-audit.lock`，再以该 venv Python 运行项目与检查；缺依赖不伪装成工具检测成功。

## 检测范围

保留现有地址/DNS/证书/HTTP/重定向/验证页等访问诊断。网站准备度另检查：

1. robots 对搜索、训练、用户触发及内容使用控制 UA 的策略。404 未发现文件与显式允许不同；获取失败为未知。禁训练不表示不能被搜索或推荐。
2. llms.txt、llms-full.txt 与同源明确声明的 Markdown。它们是辅助信息，缺失不当作禁止 AI 或强制不通过。
3. 正文提取、标题/H1 与有效语义结构化数据。小篇幅不被直接断言为依赖 JavaScript。
4. 官网组织身份、联系/关于/政策等线索。存在链接不表示已验证目标页面或声明真实性。

最多6个资源、含跳转10次HTTP、合计4MiB，网络和解析预算60秒（不含人工确认）。HTTP 提交前预约读取容量；超时的实际读取量未知时保留预约，单列 bytes_budget_used，不冒充已知 bytes_received。资源顺序与跳过原因纳入报告；不从 robots/sitemap/llms 内容任意扩展爬站。robots 明确禁止审计 UA 的辅助路径不抓，获取策略未知则保守跳过。所有下载仍走项目安全网络层，保留公网地址校验、DNS固定连接、正常TLS、同源限制及大小/超时保护。

## 分数与证据

规则 v1：访问20、搜索策略20、可提取性40、身份/联系/政策线索20，总100。训练/用户触发策略、llms、作者日期等独立观察项权重0。未知不当作通过或零分，报告显示证据覆盖率；只有加权检查均有结论才给完整分，覆盖率足够时可给明确标注的部分分。

品牌/产品候选有网页出处；竞品必须具有明确比较/替代语境，普通客户logo或外链不算竞品。未识别可留空或手工补充。用户改名和补充与原网页证据区分，不声称已验证。

## 完整导出

报告与全部检查、未知项、建议及证据一起导出。HTML 为可离线阅读/打印的静态文件，无原网页脚本或远程资源；JSON 保留完整审计。下载不取决于当前折叠状态或选中标签。

网站报告完成后，可显式进入旧的真实模型测试流程。仍须选择模型并明确启动，按供应商实际用量计费。仅从当前审计发起且URL、市场、确认品牌一致的实际任务可合并到导出；没有真实任务则明确“尚未测试”，不混用其他历史品牌。

## 本次验证

实际 Protego/Trafilatura 解析、真实 gateway 与 Chromium 三步流程、完整导出和旧问题卡/报告回归已验证；合成官网数据不算真实品牌诊断。`tests/test_site_readiness_integration.cjs` 可通过 `SIGNAL_TEST_PYTHON` 指定已安装锁定依赖的 Python。`tests/container_audit.py` 验证真实非 root 容器在无模型密钥、无外部网络时仍能生成 unknown 报告，报告与设备登录可在重启后恢复。
